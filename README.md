# SchereSteinPapier
Ein einfaches Schere, Stein, Papier Spiel in C++

Für dieses simple Schere, Stein, Papier Spiel werden 2 Spieler benötigt.

Regeln: 1. Die Eingaben können nur "Schere", "Stein" oder "Papier sein. Weitere oder zusätzliche Eingaben werden ignoriert.
2. Der erste Buchstabe **muss** groß geschrieben werden!

Viel Spaß!
