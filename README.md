# SchereSteinPapier
Ein einfaches Schere, Stein, Papier Spiel in C++

Für dieses simple Schere, Stein, Papier Spiel werden 2 Spieler benötigt.

Es gibt nur eine Regel, undzwar: Die Eingaben können nur "Schere", "Stein" oder "Papier sein. Weitere oder zusätzliche Eingaben werden ignoriert.

Viel Spaß!
